# Tabbi for Windows

The first Windows beta of Tabbi, a cozy study and focus companion: a cat at the top of your screen, with your tabs one click away.

- Install with Tabbi-Setup.exe. It installs for your account only, with no admin prompt, and adds Tabbi to the Start Menu.
- Tabbi checks for updates only when you ask: Check for Updates in the tray menu or in Settings > About. You can turn on Check automatically there if you like.
- Uninstalling keeps your Tabbi data unless you tick Delete the application data in the uninstaller.
- This beta is not code signed yet, so Windows SmartScreen may ask you to confirm before it runs.

Tabbi is free. Optional extras may come later, and the core will stay free.
